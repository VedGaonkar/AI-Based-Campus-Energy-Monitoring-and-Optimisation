Meter camera

This source reads a cumulative energy display. It does not report room occupancy or control equipment.

Connecting

Keep this foreground page and camera running. Two images are sent only for a current server capture request. Locking/backgrounding this phone can cause a visible capture gap. No catch-up readings are invented.

Open labelled virtual meter scene. The camera must actually observe its pixels. Trusted HTTPS and a reachable backend are required away from localhost.
